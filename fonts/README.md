# Fonts

Bundled so the app works offline and makes no third-party requests.

- **Bricolage Grotesque** (variable, weights 400–800, Latin subset) by
  Mathieu Triay, SIL Open Font License 1.1:
  https://github.com/ateliertriay/bricolage
- **DM Mono** (400 and 500, Latin subset) by Colophon Foundry for Google,
  SIL Open Font License 1.1: https://github.com/googlefonts/dm-mono

The Open Font License allows bundling and redistributing the fonts with
software; the full licence text is at https://openfontlicense.org.
